# 🛰️ Орбитальный симулятор

Интерактивный веб-инструмент для моделирования орбит космических аппаратов и расчёта окон связи с наземными станциями.

## 🚀 Возможности

- 3D-визуализация орбит вокруг 9 планет Солнечной системы с координатной сеткой
- Расчёт окон связи с наземной станцией по заданным координатам и минимальному углу места
- 2D-карта с трассой орбиты (Mapbox для Земли, координатная сетка для остальных планет)
- Экспорт данных в CSV: координаты, скорости, углы места, наклонная дальность
- Интерактивные настройки: высота апогея/перигея, наклонение, количество точек расчёта

## 🛠 Технологии

- Python 3.11
- Streamlit — веб-интерфейс
- Poliastro — орбитальная механика
- Plotly — 3D и 2D визуализация
- Astropy — астрономические вычисления
- Pandas — обработка данных

## 📖 Использование

### Вкладка «Визуализация»
- Выберите планету в боковой панели
- Задайте высоту апогея, перигея и наклонение
- Вращайте 3D-глобус мышью
- Смотрите параметры орбиты: период, полуось, эксцентриситет, скорости

### Вкладка «Окна связи»
- Введите долготу и широту наземной станции
- Задайте минимальный угол места (0–30)
- На 3D-глобусе орбита подсветится: зелёный — связь есть, красный — нет
- Таблица окон связи покажет время начала, конца, длительность и максимальный угол

### Вкладка «Экспорт»
- Выберите нужные столбцы
- Скачайте CSV-файл с полными данными по каждой точке орбиты
