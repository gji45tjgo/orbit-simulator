# Орбитальный симулятор

Интерактивный инструмент для моделирования орбит космических аппаратов и расчёта окон связи с наземными станциями.

## Возможности

- 3D-визуализация орбит вокруг планет Солнечной системы
- Расчёт окон радиосвязи с наземной станцией
- 2D-карта с трассой орбиты
- Экспорт данных в CSV
- Поддержка 9 планет (Земля, Марс, Венера, Юпитер и др.)

## Технологии

- Python, Streamlit, Poliastro, Plotly, Astropy

## Запуск

pip install -r requirements.txt
streamlit run app.py
